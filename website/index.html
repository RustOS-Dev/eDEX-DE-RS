eDEX-DE

A sci-fi desktop shell for Hyprland — Rust + wgpu

GitHub Latest Release

// FEATURES

🖥️

Full Wayland Compositor

Runs on Hyprland 0.55+: the shell draws on the layer shell and reserves space so your apps tile exactly into the terminal slot.

🎨

eDEX-UI Faithful Aesthetic

3-panel sci-fi layout, glowing borders, clickable hex keyboard. Twelve themes from Tron to Nord.

💻

Built-in Terminal

Multi-tab terminal on alacritty_terminal: alt screen, mouse reporting, selection, scrollback, clipboard.

📊

System Dashboard

Live CPU, RAM, network, disk, and process stats rendered directly in the UI.

🚀

App Launcher

SUPER+Space fuzzy launcher over XDG desktop entries with launch history.

🪟

Tiling Window Manager

Hyprland tiles your windows inside the eDEX frame; panels, bars and keyboard stay visible around them.

⚙️

Settings Panel

14-category settings wired to real backends, a privacy panel for Tor, Tailscale and VPNs, a notification server and a greetd greeter.

🔒

Privacy Indicators

Live status for Tor, Tailscale, VPN, WireGuard, fprintd, microphone and camera; Tor and Tailscale are controlled from the shell.

// INSTALLATION

Arch Linux (AUR)

yay -S edex-de

Then log out and select eDEX-DE from your display manager.

Debian / Ubuntu

sudo dpkg -i edex-de-*-amd64.deb
Download .deb

Fedora / RHEL

sudo rpm -i edex-de-*.x86_64.rpm
Download .rpm

From Source

cargo build --release --locked --workspace --bins
sudo install -Dm755 \
  target/release/edex-de \
  /usr/bin/edex-de
