eDEX-DE

The sci-fi desktop of RustOS — Rust, Smithay + wgpu

GitHub RustOS

// FEATURES

🖥️

Its Own Wayland Compositor

edex-comp (Smithay) runs on DRM/KMS with libinput and seatd, starts your session, locks it and runs X11 apps through Xwayland.

🎨

eDEX-UI Faithful Aesthetic

3-panel sci-fi layout, glowing borders, clickable hex keyboard. Twelve themes from Tron to Nord.

💻

Built-in Terminal

Multi-tab terminal on alacritty_terminal: alt screen, mouse reporting, selection, scrollback, clipboard.

📊

System Dashboard

Live CPU, RAM, network, disk, and process stats rendered directly in the UI.

🚀

App Launcher

SUPER+Space fuzzy launcher over XDG desktop entries with launch history.

🪟

Tiling Window Manager

Apps tile into the centre panel next to your terminal tabs; minimize, maximize and close them from the tab strip.

⚙️

Settings Panel

14-category settings wired to real backends, a privacy panel for Tor, Tailscale and VPNs, a notification server and the eDEX login screen.

🔒

Privacy Indicators

Live status for Tor, Tailscale, VPN, WireGuard, fprintd, microphone and camera; Tor and Tailscale are controlled from the shell.

// INSTALLATION

RustOS

tools/install-port.sh edex-de
svc enable edex
svc start edex

The edex service shows the eDEX login screen on tty1.

Develop

cargo run -p edex-comp -- --nested

Runs the compositor and the shell in a window of your current session.

// TECH STACK

RustOSThe operating system: a Rust kernel with a Linux-compatible ABI
Smithayedex-comp, the compositor; the shell draws on its layer shell (smithay-client-toolkit)
wgpuGPU-accelerated rendering via Vulkan + WGSL shaders
glyphonwgpu text rendering with cosmic-text layout
alacritty_terminalTerminal emulation and PTY handling
sysinfoCross-platform system statistics
zbusNotification server, NetworkManager API, UPower and login1
edex-greeter + edex-authThe eDEX login and lock screens
